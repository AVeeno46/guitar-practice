# 기타 연습

혼자 쓰는 기타 연습 웹앱. 폰에서는 홈 화면에 추가해 앱처럼, PC에서는 브라우저로 사용한다.

## 기능 계획

- [x] 메트로놈: BPM, 박자, 세분, 탭 템포, 강박
- [x] 곡: 악보(PDF/사진) + 연습 BPM·목표 BPM, 악보 보며 쓰는 미니 메트로놈, 날짜별 BPM 진행
- [x] 곡 › TAB 악보: 앱에서 직접 작성·편집(숫자 패드/키보드, 두 자리 프렛, 코드, 마디 추가·복제·삭제, 박자·리듬 변경, 되돌리기), 기법 표기(X 뮤트, 이음, 벤딩, 슬라이드, 해머링/풀링, P.M.), 쉼표, 악보 크기 조절, 마디별 템포 변경, 곡 파일 내보내기/불러오기, 메트로놈 따라 커서, 마디 구간 반복, 기타 소리 재생(오디오 시계 동기), 반복마다 +2 BPM
- [x] 연습 기록: 직접 시작 또는 메트로놈을 켜면 자동 기록, 화면별 시간·BPM, 하루 최소/목표, 연속 일수, 달력, 곡별 BPM 그래프
- [x] 연습 루틴: 크로매틱·스파이더·피킹·스케일·곡·메트로놈·자유 연습을 순서대로 묶고 항목마다 시간(분) 설정. 진행 중에는 그 연습 화면을 그대로 띄우고 남은 시간·일시정지·이전/건너뛰기, 시간이 끝나면 알림음(+진동) 뒤 다음 항목은 눌러서 시작, '1분 더', 화면 꺼짐 방지, 새로고침해도 이어짐. 항목 설정은 루틴에 고정(진행 중 바꾸면 루틴에 저장), BPM은 각 연습이 기억하는 값. 기록에 '루틴: 이름' 표시
- [x] 기본기 › 크로매틱: 손가락 패턴 24가지, 시작 프렛·방향·박당 음 수, TAB 악보에 메트로놈 따라 커서, 1마디 카운트인, 피킹 표시, 패턴별 BPM 기억·기록
- [x] 기본기 › 스파이더: 이웃한 두 줄을 오가는 손가락 독립 연습, 패턴 24가지(자주 쓰는 6개), 한 줄씩/두 줄씩 이동, 시작 프렛·방향·박당 음 수·한 바퀴마다 +1프렛, 크로매틱과 같은 TAB 커서·카운트인·패턴별 BPM 기억
- [x] 기본기 › 스케일: 펜타토닉(마이너/메이저) 지판표, 5개 포지션 박스 테두리, 블루 노트, 음 누르면 소리, 미니 메트로놈
- [x] 기본기 › 피킹: 한 줄 얼터네이트, 줄 이동(한 박마다 다음 줄), 이너·아우터(두 줄 번갈아), 줄 건너뛰기, 줄·프렛(개방현 가능)·박당 음 수, 종류별 BPM 기억
- [x] 스케일 › 7음: 메이저, 내추럴 마이너, 도리안·믹솔리디안·리디안·프리지안·로크리안. 한 줄에 3음씩(3NPS) 7개 포지션, 모드 특징음 분홍 표시와 설명, 같은 음 스케일 안내
- [x] 코드 사전 (기본기 › 코드): 근음 12개 × 종류 15개(메이저·마이너·7·m7·maj7·sus2·sus4·5·6·m6·add9·9·dim7·m7♭5·aug), 구성음·도수, 오픈 코드 + 6번줄/5번줄 근음 바레 모양 운지 다이어그램(손가락 번호·바레·×/○), 누르면 스트럼 소리
- [x] 데이터 백업: 기록 탭에서 곡·악보 파일·연습 기록·기본기 BPM·설정을 JSON 파일 하나로 내보내고 복원(지금 데이터와 합침), 마지막 백업 날짜 표시(14일 지나면 강조)
- [x] 새 버전 알림: 새 배포가 있으면 탭바 위에 "새 버전이 있어요 · 새로고침" 표시 (앱이 다시 보일 때, 30분마다 확인)
- [ ] Supabase로 기기 간 기록 동기화

## 데이터 저장

- 메트로놈 설정: `localStorage` (`gp.metronome`)
- 곡과 악보 파일, 연습 기록: IndexedDB `guitar-practice` (`songs`, `sheets`, `sessions` 저장소, v2). 폰 사진은 긴 변 2400px JPEG로 줄여 저장한다.
- 진행 중인 연습: `localStorage` (`gp.activeSession`) — 새로고침해도 이어지고, 10분 넘게 닫혀 있었으면 닫힌 시점에 끝낸다.
- 루틴: `gp.routines`(루틴 목록, 백업에 포함), `gp.routineRun`(진행 상태, 기기별이라 백업 제외). 연습 화면(크로매틱·스파이더·피킹·스케일)은 `initial`/`onSettingsChange`를 받으면 localStorage 대신 루틴 항목 설정을 쓴다(`useScreenSettings`).
- 빌드 번호: `vite.config.ts`가 빌드마다 `dist/version.json`을 만들고 같은 값을 `__APP_BUILD__`로 코드에 넣는다. 서비스 워커는 `version.json`을 캐시하지 않는다.
- 전체 백업 파일(`guitar-practice/backup` v1): IndexedDB 3개 저장소 + `gp.*` localStorage(`gp.activeSession`, `gp.lastBackup` 제외). 악보 파일은 base64. 복원 규칙: 같은 id의 곡은 `updatedAt`이 더 큰 쪽, 연습 기록은 없는 id만 추가, `gp.drills`는 날짜별로 합침, 나머지 설정은 백업 값.
- PDF 악보는 pdf.js로 직접 그린다(iOS에서도 모든 쪽이 보이도록). pdf.js는 PDF를 처음 열 때만 불러온다.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm run build   # 배포용 빌드 (dist/)
```

배포는 Vercel에서 이 저장소를 연결하면 된다 (Framework: Vite, 설정 변경 불필요).
